# Battle of Worlds

**[▶ Играть в Battle of Worlds](https://maksimkamenuka154-glitch.github.io/Battle-of-Worlds/)**

Тактическая браузерная игра на русском языке. Открой `index.html` в браузере или используй ссылку выше после публикации GitHub Pages.

## Возможности
- Две кампании: игрушки во главе с Хаги Ваги и Радужные друзья.
- Тактическое поле 7×5, размещение бойцов за энергию, перемещение и атаки соседних клеток.
- Пять уровней с финальным боссом.
- Пауза, правила боя и управление звуком.
- Адаптация для мобильных экранов; установка и сборка не требуются.

## Управление
1. Выбери бойца в панели отряда.
2. Нажми на свободную клетку левой половины поля, чтобы разместить его.
3. Выбери своего бойца и нажми на соседнего врага, чтобы атаковать.
4. Нажми **«Завершить ход»**, чтобы получить энергию и передать ход противнику.

## Публикация
GitHub Actions публикует содержимое корня репозитория через GitHub Pages. После успешного завершения workflow игра будет доступна по ссылке в начале этого файла.
